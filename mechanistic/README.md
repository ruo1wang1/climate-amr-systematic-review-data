# Mechanistic evidence dataset

This folder contains the extracted mechanistic evidence used for the framework-based synthesis.

- `mechanistic_source_data_public_minimal.csv`: public minimal version of the evidence dataset
- `mechanistic_source_data_evidence_level.csv`: expanded coded dataset retaining study-level mechanistic evidence chains
- `mechanistic_source_data_codebook.csv`: field definitions for the mechanistic dataset

The mechanistic files support the synthesis of direct biological, environment-mediated, socio-ecological, and host susceptibility pathways described in the manuscript.
