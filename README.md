# Climate-AMR Systematic Review Data and Code

This repository contains public source data and reproducible code supporting a systematic review and meta-analysis of climate-related exposures and antimicrobial resistance (AMR).

The repository is limited to materials used to generate the main evidence landscape and meta-analytic results presented in the manuscript. It does not include article full texts or any external proprietary data.

## Repository structure

- `meta/`: effect-level datasets used in the temperature and hydrological meta-analyses
- `figure_source_data/`: source data files corresponding to Figure 1A, Figure 1B, Figure 2A, Figure 2B, Figure 3A, and Figure 3B
- `mechanistic/`: extracted mechanistic evidence dataset and codebook
- `code/`: public release analysis and plotting scripts with local paths removed

## Notes

- Temperature meta-analysis files retain both World Bank and WHO regional variables because both classification systems were explored during analysis.
- Hydrological meta-analysis files reflect the final effect-level dataset used for precipitation, relative humidity, water temperature, and runoff-related analyses.
- Mechanistic evidence files provide the coded pathway dataset used for the narrative and framework-based synthesis.
