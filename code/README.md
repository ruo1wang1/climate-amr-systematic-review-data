# Public code

This folder contains public release versions of the analysis and plotting scripts used for the manuscript.

- `meta/`: scripts for the temperature and hydrological meta-analyses
- `figures/`: scripts for Figure 1A, Figure 1B, Figure 2 subgroup plots, Figure 3A, and Figure 3B

The scripts were cloned from internal working files, simplified for public release, and updated to use project-root placeholders instead of local absolute paths.

Before running the scripts in a new environment, update the required project-root environment variables or adapt the input paths to match your local repository structure.
