# Meta datasets

This folder contains the effect-level datasets used in the quantitative synthesis.

- `meta_source_data_temperature_effect_level.csv`: temperature-related effect estimates used in the temperature meta-analysis, including study identifiers, exposure labels, effect types, confidence intervals, and regional classification variables.
- `meta_source_data_hydrological_effect_level.csv`: hydrological effect-level dataset used in the meta-analyses of precipitation, relative humidity, and water temperature.

These files represent processed analytical inputs derived from the included studies and were prepared for reproducible re-analysis.
