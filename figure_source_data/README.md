# Figure source data

This folder contains the source data files corresponding to the main figures in the manuscript.

- `source_data_figure1a_map_country_counts.csv`: country-level counts used for the global evidence map
- `source_data_figure1b_sankey_assignments.csv`: study-level assignments used for the Sankey diagram
- `source_data_figure2a_temperature_primary_and_seasonal_summary.csv`: pooled temperature results used for the primary and seasonal meta-analysis panel
- `source_data_figure2b_temperature_annual_subgroup_summary.csv`: annual temperature subgroup results used for pathogen, income, and regional subgroup panels
- `source_data_figure3a_hydrological_meta_summary.csv`: pooled hydrological meta-analysis results used for the composite summary panel
- `source_data_figure3b_runoff_effect_estimates.csv`: runoff-specific effect estimates used for the runoff comparison panel

These files are intended to allow direct checking of the plotted values shown in Figures 1 to 3.
